# Contributing

Thanks for helping improve this educational project.

1. Open an issue describing the bug or pattern you want to add.
2. Keep PRs focused. Prefer the Python standard library unless a new dependency is justified.
3. Add unit tests for classification, routing, persistence, or approvals as appropriate.
4. Run `python -m unittest discover -s tests -v` before opening a PR.
5. Never commit credentials, real customer tickets, private model prompts, or sensitive logs.
6. Explain the security and failure behavior of new integrations.

The project prioritizes reliability, clear limitations, and developer usefulness over marketing copy.
